# Дашборд проектов Freedom Шапағат и ESG-показателей Freedom Holding

Один экран для CEO и CSO: благотворительные, спонсорские, социальные и экологические проекты фонда «Freedom Шапағат» и компаний группы Freedom Holding — суммы, периоды, статусы, география, динамика по годам и ключевые цифры отчётов об устойчивом развитии.

## Что внутри

- **Ключевые цифры**: ESG-проекты за последний FY и рост к прошлому году, число проектов и сумма в выборке, доля фонда, число городов и стран, численность сотрудников.
- **Фильтры**: источник (внутренний перечень / отчёты FRHC / оба), период, поиск с поддержкой сокращений («кфш» → «Казахстанская федерация шахмат»), направление, страна, город, статус, «только фонд».
- **Вкладки**: «Проекты» (диаграммы и таблица с сортировкой), «Города и страны», «Динамика по годам» (проекты в 2+ периодах), «ESG-показатели».
- Светлая и тёмная тема, работает на телефоне.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html`, `style.css`, `app.js` | приложение (без внешних библиотек) |
| `data/projects.json` | 423 записи «проект × период × источник» |
| `data/yearly.json` | итоги группы FRHC по FY2024–FY2026 |
| `data/ffg2025.json` | метрики Freedom Finance Global PLC, 2025 |
| `data/data.js` | те же данные в одном файле, который загружает страница |

После изменения JSON пересоберите `data/data.js`:

```bash
{ printf 'window.DATA={projects:'; cat data/projects.json; printf ',yearly:'; cat data/yearly.json; printf ',ffg:'; cat data/ffg2025.json; printf '};\n'; } > data/data.js
```

## Правила подсчёта

- Финансовый год FRHC: 1 апреля – 31 марта. Внутренний перечень и отчёт FFG — календарные годы.
- Проекты в EUR/USD/AMD не входят в суммы в тенге.
- Строки «в т.ч.» (разбивка Freedom Grants по вузам) не суммируются.
- Источники пересекаются, поэтому при выборе обоих сумма ориентировочная.
